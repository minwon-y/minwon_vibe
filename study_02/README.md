# My Daily Todo

카테고리·진행률·필터 기능을 갖춘 개인용 할 일 관리 웹앱.

## 사용 방법

별도 서버 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

```
study_02/index.html  →  브라우저에서 직접 열기
```

## 주요 기능

- **할 일 추가** — 텍스트 입력 후 Enter 또는 "추가" 버튼 (최대 200자)
- **카테고리 분류** — 업무 / 개인 / 공부
- **완료 체크** — 체크박스 클릭으로 완료 상태 토글 (취소선 + 흐림 처리)
- **인라인 수정** — "수정" 버튼 클릭 후 Enter 저장 / Esc 취소
- **삭제** — "삭제" 버튼 클릭 (확인 다이얼로그)
- **카테고리 필터** — 전체 / 업무 / 개인 / 공부 탭 전환
- **진행률 표시** — 전체 완료율 게이지 바 + 카테고리별 완료 수
- **영속 저장** — 페이지를 닫아도 데이터 유지 (localStorage)

## 데이터 저장

브라우저 localStorage에 JSON 형태로 저장됩니다.

- **키 이름:** `myDailyTodos`
- **저장 시점:** 추가 / 수정 / 삭제 / 완료 체크 시 즉시 저장

개발자 도구 → Application → Local Storage 에서 확인하거나 직접 삭제할 수 있습니다.

## 알려진 제한사항

- **기기 간 동기화 없음** — localStorage는 같은 브라우저·같은 기기에만 저장됩니다. 다른 기기나 다른 브라우저에서는 데이터를 볼 수 없습니다.
- **내보내기 없음** — 현재 데이터를 파일로 내보내거나 가져오는 기능이 없습니다.
- **단일 사용자** — 공유·협업 기능은 없습니다.
- **외부 라이브러리 없음** — 순수 HTML/CSS/JavaScript로만 구현되어 있습니다.
